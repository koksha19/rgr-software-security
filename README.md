# РГР: імітація TLS/SSL рукостискання

Розрахунково-графічна робота з дисципліни «Безпека програмного забезпечення» (КПІ ім. Ігоря Сікорського, ФІОТ).

Імітація рукостискання TLS між вузлами мережі з передачею даних захищеним каналом:

1. **ClientHello** — клієнт надсилає випадковий рядок (32 байти) і список шифрів.
2. **ServerHello** — сервер відповідає своїм випадковим рядком і сертифікатом X.509.
3. **Автентифікація** — клієнт перевіряє сертифікат у центрі сертифікації (підпис кореневого CA, термін дії, відкликання, ім'я вузла).
4. **Premaster** — клієнт генерує 48 байт, шифрує відкритим ключем сервера (RSA-OAEP), сервер розшифровує закритим.
5. **Ключі сеансу** — обидві сторони виводять ключі з client random, server random і premaster (HKDF-SHA256).
6. **Finished** — обидві сторони надсилають «ready» з хешем транскрипту рукостискання, зашифроване ключем сеансу.
7. **Захищений канал** — записи AES-256-GCM з порядковими номерами (захист від повтору і зміни порядку).

Розширений варіант:

- **Центр сертифікації** (`src/ca-server.js`) — HTTP-сервер з кореневим сертифікатом: підписує CSR вузлів, перевіряє сертифікати, відкликає їх.
- **Розподілена топологія** — 7 вузлів (`topologies/mesh.json`), мережа не повнозв'язна, рукостискання можливе між будь-якою парою: повідомлення пересилаються проміжними вузлами по найкоротшому маршруту (BFS). Проміжні вузли бачать лише шифротекст.
- **Повільний радіоканал** — повідомлення розбиваються на пакети розміром не більше MTU (64 байти) і передаються зі швидкістю 19200 біт/с.
- **Бродкаст** — повідомлення поширюється деревом найкоротших шляхів від вузла-джерела; кожен перехід шифрується ключем сеансу між сусідами.
- Вузол `X` має самопідписаний сертифікат і не проходить автентифікацію.

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run ca            # центр сертифікації, http://localhost:4000 (окремий термінал)
npm run basic         # базовий варіант: клієнт і сервер, чат і файл
npm run mesh          # розподілена мережа з інтерактивною консоллю
```

Команди консолі:

```
handshake <from> <to>        рукостискання між будь-якою парою вузлів
send <from> <to> <text>      повідомлення чату захищеним каналом
file <from> <to> <path>      передача текстового файлу
broadcast <from> <text>      бродкаст на всі вузли
route <from> <to>            маршрут між вузлами
revoke <node>                відкликати сертифікат вузла
topology | stats | help | exit
```

Готовий сценарій для розподіленої мережі: `node src/network.js topologies/mesh.json --script scripts/mesh.txt`.

## Структура

```
src/ca-server.js     центр сертифікації
src/certificates.js  ключі RSA, CSR і сертифікати X.509 (node-forge)
src/crypto.js        RSA-OAEP, HKDF, записи AES-256-GCM
src/link.js          канал між сусідами: пакети ≤ MTU, обмеження швидкості
src/node.js          вузол: маршрутизація, рукостискання, захищений канал, бродкаст
src/network.js       запуск мережі з файлу топології і консоль команд
topologies/          базова (2 вузли) і розподілена (7 + 1 вузол) топології
```
